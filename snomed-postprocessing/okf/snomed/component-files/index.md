# RF2 Component File Formats

* [Concept File](concept-file.md) - Clinical concept rows and concept version states.
* [Description File](description-file.md) - Description rows that attach human-readable terms to concepts.
* [Relationship File](relationship-file.md) - Concept-to-concept hierarchy and attribute relationship rows.
* [Identifier File](identifier-file.md) - Alternative identifier associations.
* [Concrete Value File](concrete-value-file.md) - Relationship rows whose target is a literal value.
* [Transitive Closure File](transitive-closure-file.md) - Generated hierarchy closure artifact.
