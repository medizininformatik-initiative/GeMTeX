# Workspace shell provenance

The current `workspace` frontend is a project-authored shell built with the public
NiceGUI and Quasar component APIs already used by this repository. It composes the
existing SNOMED policy, suggestion and review workspace without changing processing
behavior.

The implementation uses system fonts and contains no copied third-party font,
stylesheet, image, service-worker or template asset. Its generic interface
requirements are a workflow navigation rail, shared settings drawer, responsive
header, selected-stage indication, and readable bordered work surfaces.

This provenance record documents the implementation boundary; it is not legal advice.
